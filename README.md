# Magic — сайт с меню

Одностраничный сайт японской кухни Magic на обычных HTML, CSS и JavaScript. Сборка не нужна.

## Что где лежит

| Файл или папка | Что в ней |
| --- | --- |
| `index.html` | Структура страницы |
| `styles.css` | Оформление (цвета и шрифт взяты из логотипа) |
| `app.js` | Выводит меню и контакты на страницу |
| `data/menu.json` | Разделы, блюда, цены, ссылки на фото |
| `data/site.json` | Телефон, адрес, часы работы, доставка, соцсети |
| `assets/logo.png` | Логотип |
| `assets/photos/` | Фотографии блюд |
| `admin/` | Редактор сайта, страница `/admin/` |

## Как владельцу менять цены, фото и контакты

Для этого есть редактор по адресу `https://<ваш-сайт>/admin/`. В нём не нужно трогать код: меняете поля, добавляете фото, нажимаете «Опубликовать», и через минуту изменения видны на сайте. Первоначальная настройка и вход описаны в файле [ADMIN.md](ADMIN.md).

## Запуск у себя на компьютере

Меню подгружается из файлов `data/*.json`, поэтому страницу нельзя открывать двойным кликом. Запустите в папке проекта:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Публикация на GitHub Pages

1. На GitHub откройте репозиторий: Settings, затем Pages.
2. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<имя-аккаунта>.github.io/<имя-репозитория>/`.

## Правка без редактора

Файлы `data/menu.json` и `data/site.json` можно править прямо на GitHub (значок карандаша у файла) и сохранять кнопкой Commit changes. Фото загружаются в папку `assets/photos/` кнопкой Add file, затем имя файла вписывается в `photo` нужного блюда, например `"photo": "assets/photos/philadelphia.jpg"`.
