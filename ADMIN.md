# Как пользоваться редактором сайта

Редактор открывается по адресу `https://<ваш-сайт>/admin/`. В нём можно менять цены, названия, составы, добавлять блюда и фото, править телефон, адрес и часы работы.

## Один раз: настройка (делает тот, кто выкладывает сайт)

1. Выложите проект в репозиторий на GitHub и включите GitHub Pages (см. `README.md`).
2. Откройте файл `admin/config.yml` и замените `OWNER/REPO` на адрес репозитория, например `ivan-petrov/magic-sushi`. Сохраните (Commit changes).

## Один раз: токен доступа для владельца

Редактор сохраняет изменения в репозиторий, поэтому ему нужен ключ доступа от аккаунта GitHub. Это делается один раз.

1. Зайдите на GitHub под аккаунтом, где лежит репозиторий.
2. Откройте Settings, затем Developer settings, затем Personal access tokens, затем Fine-grained tokens, затем Generate new token.
3. Название: `magic-editor`. Срок действия: на ваше усмотрение, например 1 год.
4. В разделе Repository access выберите Only select repositories и отметьте репозиторий сайта.
5. В разделе Permissions, Repository permissions найдите Contents и поставьте Read and write.
6. Нажмите Generate token и скопируйте токен (он показывается один раз).

Храните токен как пароль: тот, у кого он есть, может менять сайт.

## Как менять сайт

1. Откройте `https://<ваш-сайт>/admin/` и нажмите Sign in with GitHub Token. Вставьте токен.
2. Слева выберите «Меню» или «Контакты и условия».
3. Чтобы поменять цену, откройте нужный раздел и блюдо, измените число в поле «Цена в рублях».
4. Чтобы добавить блюдо, откройте раздел и нажмите «Добавить блюдо». Заполните название, состав, вес, цену. Фото можно загрузить кнопкой в поле «Фото».
5. Нажмите «Опубликовать» (Save, затем Publish). Через минуту-две изменения появятся на сайте.

## Советы по фото

- Горизонтальные снимки с пропорциями 4:3, блюдо по центру, однотонный фон.
- Размер файла до 1–2 МБ, иначе сайт будет медленно открываться на телефоне. Фото с телефона можно предварительно уменьшить в любом редакторе или сервисе сжатия.
- Блюдо без фото показывается с цветной заглушкой, поэтому добавлять фото можно постепенно.

## Если что-то не работает

- Страница `/admin/` пустая или не загружается: проверьте интернет и что в `admin/config.yml` указан правильный репозиторий.
- Пишет, что нет доступа: токен истёк или у него нет права Contents: Read and write на этот репозиторий. Создайте новый токен по инструкции выше.
- Изменения не видны на сайте: подождите пару минут и обновите страницу с очисткой кэша (Ctrl+F5).
